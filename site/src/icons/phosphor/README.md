# Icons: Phosphor 2.1.1 (MIT, see LICENSE)

Phosphor's own files, fetched unchanged from
`cdn.jsdelivr.net/npm/@phosphor-icons/core@2.1.1/assets/<weight>/<name>.svg`.
Chosen by Hidde 2026-09-24. Never draw an icon by hand: `scripts/iconcheck.py`
refuses it on push. To add one, fetch the file into the right weight folder.

The website stands in for the app's SF Symbols (which Apple licenses for Apple
platforms only). `bold` matches SF Symbols' regular weight best at UI sizes.
